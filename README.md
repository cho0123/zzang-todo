# ⚡ 짱구 Manager (ToDo)

Firebase Firestore 기반 단기/장기 일정 관리 웹앱. 단일 `index.html` 정적 페이지입니다.

## 주요 기능
- **단기(1회성) / 장기(빌드업 플랜)** 일정 구분, 좌우 2단 레이아웃(모바일 반응형)
- 카테고리(보이스튜닝 / 보티즈 / 머니 / 일반), 오전·오후 시간
- **고정 / 반복 / 우선(중요)** 토글, 날짜 옆 `오늘` 버튼
- 장기 플랜 **마감일(선택)** + D-day, 마감 임박(D-3 이내) 항목은 오늘칸 상단에 `⏰` 자동 노출
- 단기 날짜 배지: 오늘 → `오늘`, 처리 안 된 지난 일정 → `D+n`
- 스와이프 완료, 완료 36시간 후 자동 삭제

## 정렬 규칙
- **단기**: `고정 > 날짜(빠른 순) > 우선` 순으로 상단, 아무 속성 없는 항목은 카테고리(보이스튜닝 > 보티즈 > 머니 > 일반)순, 완료는 하단
- **장기**: 카테고리순 → 같은 카테고리 내 우선 항목 상단 → 마감일 가까운 순, 완료는 하단

## 배포 (Netlify)
### 방법 1) 드래그 앤 드롭
1. [app.netlify.com](https://app.netlify.com) 로그인 → **Sites**
2. 이 폴더를 드롭존에 끌어다 놓기 (`.claude/`는 제외하고 올려도 됨)

### 방법 2) Git 연동 (권장 — 이후 수정 시 자동 재배포)
1. 이 폴더를 GitHub 등 원격 저장소에 푸시
2. Netlify → **Add new site → Import an existing project**로 저장소 연결
3. 빌드 명령 없음 / publish 디렉터리 `.` (`netlify.toml`에 설정됨)

## 로컬 실행
```bash
python -m http.server 8777
```
→ http://localhost:8777/index.html

## 데이터
Firebase Firestore(`cho-works` 프로젝트, `tasks` 컬렉션)를 공유 백엔드로 사용합니다.
웹 클라이언트 API 키는 공개되어도 무방한 값이며, 실제 접근 제어는 **Firestore 보안 규칙**으로 관리합니다.
